# Entrega del Proyecto

Estimados estudiantes,

Para el avance del proyecto que han venido desarrollando durante el último mes, deberán realizar la entrega de una versión estructurada y documentada de su sistema, utilizando buenas prácticas propias de la ingeniería de software.

La entrega debe realizarse mediante un repositorio en GitHub, el cual debe contener el proyecto completo, funcional y organizado.

Adicionalmente, el repositorio debe incluir los siguientes archivos en formato `.md` (Markdown), correctamente redactados y con información clara.

## 1. Documento principal del proyecto

Debe incluir:

- Descripción general del sistema.
- Objetivo del proyecto.
- Tecnologías utilizadas.
- Instrucciones para ejecutar el sistema.
- Evidencia visual, como capturas de pantalla del sistema funcionando.

## 2. Arquitectura del sistema

Debe explicar:

- Tipo de arquitectura utilizada, por ejemplo cliente-servidor, MVC u otra.
- Componentes principales, como frontend, backend y base de datos.
- Forma en que los componentes se comunican entre sí.
- Diagrama representativo, ya sea como imagen o mediante una herramienta como Mermaid.

## 3. Diseño de base de datos

Debe describir:

- Tablas principales.
- Relaciones entre tablas.
- Justificación básica del diseño.
- Script o fragmentos de creación, si aplica.

## 4. Documentación de servicios del sistema

Si aplica, debe incluir:

- Endpoints disponibles.
- Métodos HTTP utilizados, como `GET`, `POST`, `PUT` y `DELETE`.
- Parámetros de entrada.
- Respuestas esperadas.

## 5. Instrucciones de ejecución

Debe explicar:

- Requisitos previos.
- Pasos para levantar el proyecto.
- Uso de Docker o entorno local, si aplica.

## 6. Mejoras futuras

Debe incluir una propuesta con:

- Funcionalidades pendientes.
- Posibles optimizaciones.
- Ideas de evolución del sistema.

## Criterios de evaluación

- El proyecto debe estar funcional al momento de la revisión.
- La documentación debe ser coherente con lo implementado.
- Se evaluará claridad, orden, comprensión técnica y calidad del trabajo presentado.
- No se evaluará únicamente que el sistema funcione, sino que el grupo demuestre dominio del proceso de desarrollo.
