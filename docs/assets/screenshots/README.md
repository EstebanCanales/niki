# Capturas de Pantalla

Colocar en esta carpeta la evidencia visual del sistema funcionando.

Capturas recomendadas:

- `01-desktop-home.png`: pantalla principal de Niki Desktop.
- `02-chat.png`: chat funcionando con una respuesta del asistente.
- `03-tasks.png`: panel de tareas con elementos creados.
- `04-settings.png`: configuracion de backend, runtime y NikiNotch.
- `05-notch.png`: NikiNotch abierto y conectado.

Estas imagenes deben agregarse antes de la entrega final si el profesor solicita evidencia visual dentro del repositorio.
