# Qwen3-TTS voice interaction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace per-request Piper synthesis with a persistent local Qwen3-TTS worker and make Niki's Spanish voice interaction natural and autonomous.

**Architecture:** The NestJS voice service keeps a single Qwen3 Python process alive and serializes synthesis requests over newline-delimited JSON. The Swift client keeps its existing VAD and audio playback contract, migrating old voice IDs and sanitizing assistant text for speech.

**Tech Stack:** NestJS/TypeScript, Python 3.12+, `qwen-tts`, PyTorch, soundfile, Swift/AVFoundation.

## Global Constraints

- Do not start the backend or macOS frontend during implementation or verification.
- Preserve `POST /voice/synthesize` response fields (`ok`, `audio`, `format`, `mime`, `error`, `duration`).
- Use Qwen3-TTS for synthesis; Piper is not the active provider.
- Keep user-facing voice copy in Spanish.
